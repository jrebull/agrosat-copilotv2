# Revisiones externas, versionadas

adjuntos. Se versionan aquí por un motivo concreto: **la auditoría del plan no pudo comprobar la
mitad de su trazabilidad porque estos documentos no estaban bajo control de versiones**, y su
informe lo declaró como límite propio. Trazar contra un archivo que no está en el repositorio es
exactamente el defecto que US-123 existe para eliminar, así que se corrige aquí en lugar de
esperar a esa historia.
